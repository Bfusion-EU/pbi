# Insights Command Center (Home) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Insights pack Home "Story Navigator" with the approved command center (spec
`docs/superpowers/specs/2026-10-31-insights-command-center-design.md`): icon navigation rail, pulse KPIs
with sparklines, PMO view (act-now list, area health, next 30 days) and Executive view (3 decisions, 4
answers), switched by bookmarks.

**Architecture:** The pack is generated by Python (`Insights/_generator`). A new module `ext_home.py`
registers report-level measures (`Story | Home · …`) and builds the Home page; it replaces
`pages.build_home`. `pbir.py` gains visual groups and a bookmark registry; `build.py` writes bookmarks
and icon resources. Rail icons are PNGs (rendered once by a Node script, committed) shown by image
visuals with a transparent page-navigation button on top.

**Tech Stack:** Python 3.14 + pytest 9 (generator and tests), PBIR JSON (report schema 2.x, bookmark
2.1.0), DAX report-level measures, Node 20 + `@resvg/resvg-js` + `@tabler/icons` (icon rendering only),
Power BI Desktop (visual check).

## Global Constraints

- Native Power BI visuals only. No model change: every new measure is report-level, folder `Story\Home`, prefix `Story | Home · `.
- Reuse an existing story measure wherever one already answers the question (one definition per number).
- Page 1800 × 1000, `FitToPage`, canvas `#141C2F`; cards `#1B2540`, radius 14; text `#E8ECF4`, labels `#8C98B3`; accent `#E8612A`; status red `#FF8A80`, amber `#F2C46B`, teal `#5DCAA5`.
- Portfolio and Program slicers on Home are synced report-wide (existing sync groups).
- Bookmarks change display only (`suppressData: true`), so slicer picks survive the view switch. Default view: PMO.
- Do not use the model's `Status Report | … Previous …` measures (DATEADD −1 day, wrong).
- Change chips only where history exists; blank (not 0) when there is no previous value.
- `python build.py --check` (schema, references, layout) and `python dax_check.py` (0 errors) must pass before every commit that touches the report.
- Never build into the real report folder while testing layout tweaks: use `INSIGHTS_OUT=<scratch>`; the final task builds the real report.
- All paths below are relative to `C:\pbi-rn\OneDashboards-renamed\DecisionHome-work\Insights\_generator` unless they start with `C:\`.

```python
BOOKMARK_SCHEMA = "https://developer.microsoft.com/json-schemas/fabric/item/report/definition/bookmark/2.1.0/schema.json"
BOOKMARKS = []  # filled by page builders, written by build.py


def bookmark(display_name, key, page_id, groups_hidden):
    """Display-only bookmark: shows/hides visual groups on one page; data and slicers untouched."""
    name = uid("bookmark", key)
    BOOKMARKS.append({
        "$schema": BOOKMARK_SCHEMA, "displayName": display_name, "name": name,
        "options": {"suppressData": True, "applyOnlyToTargetVisuals": True,
                    "targetVisualNames": list(groups_hidden)},
        "explorationState": {"version": "1.3", "activeSection": page_id,
                             "sections": {page_id: {"visualContainers": {},
                                                    "visualContainerGroups": {g: {"isHidden": h}
                                                                              for g, h in groups_hidden.items()}}}}})
    return name


def _relink(btn, props):
    btn["visualContainerObjects"]["visualLink"] = [{"properties": props}]
    return btn


def bookmark_button(text, bookmark_name, tooltip="", **kw):
    return _relink(nav_button(text, "", tooltip, **kw),
                   {"show": b(True), "type": s("Bookmark"), "bookmark": s(bookmark_name), "tooltip": s(tooltip)})


def drill_button(text, target_page, tooltip="", **kw):
    return _relink(nav_button(text, "", tooltip, **kw),
                   {"show": b(True), "type": s("Drillthrough"), "drillthroughSection": s(target_page),
                    "tooltip": s(tooltip)})
```

```javascript
// One-off: renders the command-center rail icons (Tabler outline) to 96 px PNGs.
// Usage (from a scratch folder):  npm i @resvg/resvg-js @tabler/icons  &&  node <path>/make_icons.mjs <outDir>
import { Resvg } from '@resvg/resvg-js';
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { createRequire } from 'node:module';
import path from 'node:path';

const require = createRequire(path.join(process.cwd(), 'x.js'));
const iconDir = path.join(path.dirname(require.resolve('@tabler/icons/package.json')), 'icons', 'outline');
const ICONS = { cc: 'layout-dashboard', exec: 'crown', portfolio: 'briefcase', finance: 'coin-euro',
  resources: 'users', schedule: 'calendar-time', risk: 'alert-triangle', benefits: 'trending-up',
  governance: 'shield-check' };
const COLOURS = { grey: '#8C98B3', white: '#FFFFFF' };
const out = process.argv[2];
mkdirSync(out, { recursive: true });
for (const [key, file] of Object.entries(ICONS)) {
  const svg = readFileSync(path.join(iconDir, `${file}.svg`), 'utf8');
  for (const [cname, hex] of Object.entries(COLOURS)) {
    const png = new Resvg(svg.replaceAll('currentColor', hex), { fitTo: { mode: 'width', value: 96 } }).render().asPng();
    writeFileSync(path.join(out, `rail-${key}-${cname}.png`), png);
  }
}
console.log('done');
```

```python
"""Home — the command center (replaces pages.build_home).

Measures: report-level, prefix "Story | Home · ", folder Story\\Home. Built on the chapter measures;
history-based numbers (sparklines, change chips) come from FactStatusReport snapshots per report month.
Layout: see build() (Task 4/5). Spec: docs/superpowers/specs/2026-10-31-insights-command-center-design.md
"""
import pbir
from pbir import NAVY, ORANGE, TEAL, AMBER, RED, GREY, MUTED
from story_measures import add, money, T, D, I

PX = "Story | Home · "
FOLDER = "Story\\Home"
C_RED, C_AMBER, C_TEAL = "#FF8A80", "#F2C46B", "#5DCAA5"
PROJECTS = "FILTER ( VALUES ( DimProject[Id] ), NOT ISBLANK ( DimProject[Id] ) )"


def hm(name):
    return PX + name


def _add(name, dtype, expr, fmt=None, desc=None, folder=FOLDER):
    add(hm(name), dtype, expr, fmt, folder, desc)


# ---------------------------------------------------------------- top bar
_add("Greeting", T, """
VAR _h = HOUR ( NOW () )
RETURN IF ( _h < 12, "Good morning", IF ( _h < 18, "Good afternoon", "Good evening" ) )""")

# ---------------------------------------------------------------- act now (per project)
_add("Act Score", I, f"""
VAR _one = HASONEVALUE ( DimProject[Id] ) && NOT ISBLANK ( SELECTEDVALUE ( DimProject[Id] ) )
    && SELECTEDVALUE ( DimProject[State_Value] ) = "Active"
VAR _h = SELECTEDVALUE ( DimProject[OverallHealth_Value] )
RETURN
    IF ( _one,
        SWITCH ( TRUE (),
            LEFT ( _h, 3 ) = "(3)", 100,
            [Story | EAC Variance %] > 0.05, 90,
            [Story | Baseline · Finish Slip (days)] > 10, 80,
            [Story | Project · Overdue Tasks] > 10, 60,
            [Story | Status · Days Since Report] > 30, 50,
            [Story | Project · Failing Rules] > 0, 40 ) )""", "0",
     "Impact rank of the worst reason an active project needs attention (blank = no reason).")
_add("Act Reason", T, f"""
VAR _s = [{hm("Act Score")}]
RETURN
    SWITCH ( _s,
        100, "Reported off track",
        90, "EAC " & FORMAT ( [Story | EAC Variance %], "+0%" ) & " over budget",
        80, FORMAT ( [Story | Baseline · Finish Slip (days)], "+0" ) & " days vs baseline",
        60, FORMAT ( [Story | Project · Overdue Tasks], "0" ) & " overdue tasks",
        50, "No status report for " & FORMAT ( [Story | Status · Days Since Report], "0" ) & " days",
        40, FORMAT ( [Story | Project · Failing Rules], "0" ) & " Plan Insights rule(s) failing" )""")
_add("Act Colour", T, f"""
VAR _s = [{hm("Act Score")}]
RETURN IF ( ISBLANK ( _s ), BLANK (), IF ( _s >= 80, "{C_RED}", "{C_AMBER}" ) )""", folder=FOLDER + "\\Colours")
_add("Act Count", I, f"COUNTROWS ( FILTER ( {PROJECTS}, NOT ISBLANK ( [{hm('Act Score')}] ) ) ) + 0", "0")

_add("Briefing", T, f"""
VAR _n = [{hm("Act Count")}]
VAR _a = [Story | Active Projects]
VAR _ob = [Story | Projects Over Budget] + 0
VAR _sl = [Story | Baseline · Late Projects] + 0
VAR _nm = EOMONTH ( TODAY (), 0 ) + 1
VAR _op = CALCULATE ( [Story | Over-allocated People], DimDate[MonthStart] = _nm, REMOVEFILTERS ( DimDate ) ) + 0
RETURN
    IF ( _n = 0, "No active project needs a decision this week. Keep the data fresh.",
        FORMAT ( _n, "0" ) & " of " & FORMAT ( _a, "0" ) & " active projects need a decision — "
            & FORMAT ( _ob, "0" ) & " over budget, " & FORMAT ( _sl, "0" ) & " slipping, "
            & FORMAT ( _op, "0" ) & " people above 100% in " & FORMAT ( _nm, "mmmm" ) & "." )""")

# ---------------------------------------------------------------- history from status-report snapshots
# Per report month: each project's latest report in that month. Months older than 6 return blank (sparkline window).
LATEST = """CALCULATE ( MAX ( FactStatusReport[{col}] ),
            FactStatusReport[Report_ReportEnd] = CALCULATE ( MAX ( FactStatusReport[Report_ReportEnd] ) ) )"""
WINDOW = "MAX ( DimDate[MonthStart] ) >= EDATE ( EOMONTH ( TODAY (), -1 ) + 1, -5 ) && MIN ( DimDate[MonthStart] ) <= TODAY ()"
_add("EAC Var % (reports)", D, f"""
VAR _b = SUMX ( {PROJECTS}, {LATEST.format(col="Budget")} )
VAR _f = SUMX ( {PROJECTS}, {LATEST.format(col="Forecast")} )
```
